# 233战法自动扫描系统

基于A股"233战法"的自动化扫描与可视化系统。通过分层筛选，在资金开始进攻后寻找当日确定性更高的短线机会。

## 核心理念

> 不预测涨停，而是在资金已经开始进攻之后，通过层层筛选，寻找当天确定性更高的机会。

- **2个核心原则**：板块优先于个股；跟随而非预测
- **3个筛选标准**：股性活跃（涨停基因）、市场辨识度（成交额/换手）、量价结构（红肥绿瘦+放量）
- **3个确认信号**：板块确认、龙头确认、买点确认（四条件共振）

## 功能概览

| 模块 | 功能 | 触发时间 |
|------|------|----------|
| 盘前筛选 | 涨停基因 → 量价结构 → 辨识度评分 → 核心股池 | 08:30 |
| 盘中扫描 | 板块确认 → 龙头确认 → 买点确认（四条件共振） | 09:25 / 10:30 / 13:00 / 14:30 |
| Web可视化 | 股池查看、扫描结果、运行日志、参数配置、历史记录 | 浏览器访问 |
| 历史存档 | 每日股池及每次盘中扫描结果自动存档为JSON | 扫描完成后自动 |

## 快速开始

### 环境要求

- Python 3.9+
- macOS / Linux

### 安装

```bash
git clone git@github.com:shuxinlei/233.git
cd 233
pip install -r requirements.txt
```

### 运行

**方式一：自动调度模式（全天运行）**

```bash
python main.py
```

程序会在交易日自动执行：
- 08:30 盘前筛选
- 09:25 / 10:30 / 13:00 / 14:30 盘中扫描
- 15:30 自动结束

**方式二：手动运行单次任务**

```bash
python main.py --mode pre        # 只跑盘前筛选
python main.py --mode intraday   # 只跑盘中扫描
```

**方式三：Web可视化**

```bash
python app.py
```

浏览器打开 http://127.0.0.1:5000 ，可在页面上手动触发筛选/扫描、查看结果、调整参数、浏览历史记录。

## 筛选流程

### 盘前筛选（核心股池构建）

```
涨停池数据(近30日)
    ↓ 涨停次数 ≥ 阈值
涨停基因池
    ↓ 红绿比 ≥ 1.5 + 量比 ≥ 1.2 + 换手 ≥ 3%
量价筛选池
    ↓ 涨停基因40% + 流动性30% + 量价30% 加权评分
核心股池 Top50
```

### 盘中扫描（三重确认）

```
板块确认: 概念+行业板块涨幅排名 → 取前8
    ↓
龙头确认: 核心股池中 涨幅≥5% + 量比≥1.5 + 换手≥5%
    ↓
买点确认: 四条件共振
    ├─ 板块在涨 (≥2%)
    ├─ 核心在动 (≥5%)
    ├─ 量能在放 (量比≥1.5)
    └─ 股价突破MA5
```

## 策略参数

所有参数在 `config.py` 中集中管理，也可通过 Web 页面实时调整：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `PRE_MARKET_TIME` | 08:30 | 盘前筛选触发时间 |
| `SCAN_TIMES` | 09:25/10:30/13:00/14:30 | 盘中扫描时间节点 |
| `ZT_HISTORY_DAYS` | 30 | 涨停基因回看交易日数 |
| `ZT_MIN_COUNT` | 1 | 最少涨停次数 |
| `RED_GREEN_RATIO` | 1.5 | 红肥绿瘦最小比值 |
| `VOLUME_RATIO` | 1.2 | 量比最小值 |
| `TURNOVER_MIN` | 3.0% | 最低换手率 |
| `POOL_SIZE` | 50 | 核心股池大小 |
| `TOP_SECTOR_COUNT` | 8 | 取前N个板块 |
| `STOCK_RISE_MIN` | 5.0% | 龙头确认最低涨幅 |
| `STOCK_VOLUME_RATIO` | 1.5 | 龙头确认最低量比 |

## 历史数据

每次盘前筛选和盘中扫描完成后，自动存档到 `history/` 目录：

| 文件 | 内容 |
|------|------|
| `YYYYMMDD_pool.json` | 当日核心股池（含代码、名称、板块、评分等） |
| `YYYYMMDD_scan_HHMM.json` | 盘中扫描结果（含四条件共振状态） |

通过 Web 页面「历史记录」Tab 可查看所有存档，左侧列表选择，右侧展示完整数据表格。

## 数据源

本项目使用 [AkShare](https://akshare.akfamily.xyz/) 开源数据接口，不依赖任何付费API：

| 数据 | 接口 | 说明 |
|------|------|------|
| 涨停池 | `stock_zt_pool_em` | 东方财富，含所属板块 |
| 日K线 | `stock_zh_a_daily` | 新浪财经，前复权 |
| 实时行情 | `stock_zh_a_spot` | 新浪财经，全市场快照 |
| 概念板块 | `stock_board_concept_name_em` | 东方财富 |
| 行业板块 | `stock_board_industry_name_em` | 东方财富 |
